Gerador de QR com tracking

Como usar
  1. Destino: para onde o QR leva. Ex.: LinkedIn, Página de carreiras, Newsroom.
  2. Mídia: onde o QR será usado. Ex.: placa, digital-card, flyer, email.
  3. Nome do evento: vira a campanha no Google Analytics. Escreva como quiser, o gerador padroniza. Ex.: Brasa Summit 2026 vira brasa-summit-2026.
  4. Link específico (opcional): use só se este evento tem um link próprio, como um forms só dele. Se deixar vazio, o QR leva ao link padrão do destino.
  5. Clique em Salvar e gerar QR. O QR só aparece depois de salvo, e fica guardado na aba Histórico.
  6. Baixe o PNG (slides, e-mail, redes) ou o SVG (placas e material impresso: envie à gráfica).
  7. Antes de imprimir, escaneie o QR com o celular e confirme que abre o lugar certo.

Exemplos

  • Placa do Brasa Summit levando ao LinkedIn: Destino = LinkedIn · Mídia = placa · Evento = Brasa Summit 2026.
  • Cartão digital levando ao forms de talentos: Destino = Forms de talentos · Mídia = digital-card · Evento = Select Experience 2026 · Link específico = o link do forms deste evento.
  • Mesmo evento em duas mídias: gere duas vezes, uma com placa e outra com digital-card. Assim o GA4 mostra qual mídia trouxe mais scans.
  • Destino que só serve para um evento: clique em + Novo, preencha, e desmarque "Memorizar este destino".

Destino ou mídia novos

  • Clique em + Novo (ou + Nova) e preencha os campos que aparecem. Clique de novo para voltar à lista.
  • Memorizar marcado: o item entra na lista e aparece nos próximos QR. Desmarcado: vale só para este QR.
  • O utm_source do destino sempre começa com qr-. Ex.: qr-forms-talentos.

Para salvar é preciso conectar o GitHub uma vez neste navegador (seção Conexão com o GitHub, no fim da página). Depois de salvar um destino ou link novo, espere cerca de 1 minuto antes de imprimir ou testar.

Como criar um token novo

Você precisa de um token para salvar QR e cadastrar destinos. Se o atual venceu ou nunca foi criado, siga os passos. Os QR já impressos não são afetados.

Abrir a página do GitHub

  1. Entre no GitHub com a conta larissapbaltazar-gif.
  2. Token name: qr-gerador. Expiration: 90 dias (ou o prazo que preferir).
  3. Repository access: escolha Only select repositories e marque só qr-link.
  4. Em Permissions → Repository permissions, defina Contents: Read and write.
  5. Clique em Generate token e copie o valor (github_pat_…). Ele aparece uma única vez.
  6. Volte aqui, cole em Conexão com o GitHub e clique em Guardar token.

Caminho manual, se o botão não abrir: GitHub → foto do perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
Endereço: github.com/settings/personal-access-tokens/new
